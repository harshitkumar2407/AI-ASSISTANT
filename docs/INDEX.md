## 🔄 Common Workflows

### First-Time Setup

1. Read [SETUP.md](./SETUP.md)
2. Configure [ENV_VARIABLES.md](./ENV_VARIABLES.md)
3. Set up email with [EMAIL_SETUP.md](./EMAIL_SETUP.md)
4. Review [AUTH_FLOW.md](./AUTH_FLOW.md)
5. Start developing with [DEVELOPMENT.md](./DEVELOPMENT.md)

### Adding a New Feature

1. Check [API_REFERENCE.md](./API_REFERENCE.md) for endpoint specs
2. Review [COMPONENTS.md](./COMPONENTS.md) for frontend structure
3. Follow [DEVELOPMENT.md](./DEVELOPMENT.md) workflow
4. Add tests from [TESTING.md](./TESTING.md)

### Deploying to Production

1. Review [ENV_VARIABLES.md](./ENV_VARIABLES.md) production settings
2. Check [ARCHITECTURE.md](./ARCHITECTURE.md) for deployment strategy
3. Refer to [SETUP.md](./SETUP.md) troubleshooting section
